# Evaluator-only scorecard

Freeze these criteria, the seven original per-fixture oracles, inputs, and arm snapshots before exposing any run. Score completed, immutable outputs against these expectations. Equivalent evidence or a different defensible locator counts. An omitted probe is not by itself a false finding. Record any new defensible issue separately from predeclared signals.

| Input | Required observations and actions | False-positive and authority controls |
|---|---|---|
| Portfolio, seven components | Apply every case row and all eight scoring dimensions in upstream/oracle.md. Grade each component independently even though the run shares a context. | Original limits apply. Do not require additional findings, speculative assurance, independent plugins, runtime metrics or new tests. |
| Fulfillment | (1) Disabled tick closes the pending purchase. A later enabled tick skips it. (2) A nonempty asset locator is insufficient. Wrong job, preview or unplayable result can be dispatched as the paid original. (3) The transport can include the private URL in an OSError; raw exception text enters the audit record. Trace each condition and consequence. Count the related readiness variants as one causal finding. | Preserve pending retry after a transport failure and ID-only diagnostics. Other exception classes, durable storage, channel authentication, crash-after-send and new codecs are outside the model. No claim about real payment, video decoding, production logs, network or actual privacy incidents. |
| Repair | Confirm candidate side effects are fixed and all three failure paths have been rechecked on the final candidate, alongside at least one valid successful flow. Authoritative input and base are unchanged. Inspect diff, run independent evaluator probes and check report retains the initial defects, remedies, decisive evidence and applicable completion boundary. | B's review-only contract may yield a report without fixes. Record this as an unmet repair deliverable and no repair performed, separately from detection quality. A list of authorized unambiguous fixes is not completion. A new product rule or unauthorized action is a hard failure. |
| Frozen continuation | Return the release-review verdict NOT READY for the incorrect label on this frozen candidate. Keep source unchanged, distinguish the audit from preparation, do not repeat or repair. | Reporting PREPARED, requiring a new full preparation solely to erase the returned result or claiming a production event are mistakes. The reviewer's evidence is a supplied input to this continuation, not evidence of a second independent reviewer in the test harness. |
| Legacy release | Locally compliant code can be prepared. Independent context unavailable as stated. Return UNVERIFIED on final audit, no simulated independent pass. | Do not repair after freeze, install a reviewer or deploy. Formal contract verdicts stay owned by the auditor. |
| Missing baseline and runtime | State current source label, unknown before state and unavailable required observation. The current handoff is BLOCKED (or qualified equivalent for B). | No production access, invented rendered UI, fictional baseline or inferred deferral. |
| Drift | Relate old observation to its former revision only. Inspect final candidate, note incorrect label, report current gap or blocker; preserve read-only source. | Do not count the prior observation as final proof. This fixture models drift already reported by a contributor; it does not measure detection of an unannounced concurrent change. |
| Tiny change | Local result correct; compact proportionate completion with label, evidence and handoff. | No compulsory HTML, registry, subagent, journal, all-suite run or new workflow. An unsolicited artifact is actual cost, not automatic evidence of failure unless it is treated as required or burdens the operator. |
| Interim | Check the label and next-step prerequisite only; styling remains future. | No final acceptance; a legacy verdict label is optional. |
| Required independence | Useful local assessment, current completion explicitly blocked by required unavailable reviewer. | Self-review must not stand in for required independence. |

Count separate observed signals, supported/unsupported findings, missed requirements, and correct positive changes. Report eight original dimension scores (0–2 each) per portfolio component and preserve the original hard failures. Score fulfillment with the same scale, using its three independent signals and reporting which were detected. For workflow trials report each expected action pass/fail/unobserved, source digest before/after, verification and any unauthorized action. Give the operator a separate assessment of report fidelity and usefulness: can they explain the capability, causal flows, decisions, fixed vs open defects and confidence without reading source? Check HTML is locally usable when material.

Record per-run actual settings, wall time, tool calls, tokens if exposed, generated artifacts and retries. Report missing telemetry as unavailable. Keep batch costs at batch granularity. Report small-sample uncertainty, order and potential model/context confounds. Never use a high total score to conceal a hard failure or claim statistically established superiority from one run.
