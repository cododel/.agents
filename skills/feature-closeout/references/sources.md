# Methodological sources

The semantic inventory, reverse requirements trace, concrete comparison of simpler alternatives, independent challenge and owner-facing visual report adapt Engineering Review v0.1.0. Its REFERENCES.md credits the following original influences. These links document provenance only. Local authority, evidence and repair procedures govern closeout.

| Reference | Design influence and adaptation |
|---|---|
| [Compound Engineering / ce-code-review](https://github.com/EveryInc/compound-engineering-plugin/tree/main/skills/ce-code-review) ([maintainability lens](https://github.com/EveryInc/compound-engineering-plugin/blob/main/skills/ce-code-review/references/personas/maintainability-reviewer.md), [validation](https://github.com/EveryInc/compound-engineering-plugin/blob/main/skills/ce-code-review/references/finish-merge.md)) | Risk-based reviewers, structured findings, independent challenge and decision routing. No fixed line-count severity, no implicit cross-provider egress, no mandatory plugin orchestration. |
| [Visual Explainer / diff-review](https://github.com/nicobailon/visual-explainer/blob/main/plugins/visual-explainer/commands/diff-review.md), [fact-check](https://github.com/nicobailon/visual-explainer/blob/main/plugins/visual-explainer/commands/fact-check.md) | Before/after diagrams and a separate factual check. Presentation consumes an evidence-backed report; it is optional and cannot turn static inference into a runtime observation. |
| [Superpowers / verification-before-completion](https://github.com/obra/superpowers/tree/main/skills/verification-before-completion), [requesting-code-review](https://github.com/obra/superpowers/tree/main/skills/requesting-code-review) | Verified completion and review boundaries. Explicit whole-task base, not a last-commit assumption. |
| [Trail of Bits / spec-to-code-compliance](https://github.com/trailofbits/skills/tree/main/plugins/spec-to-code-compliance) | Trace requirements both directions, seek counterevidence, account for unchecked obligations. No automatic rejection of a consequential concern based solely on one agent's disagreement. |
| [gstack / review](https://github.com/garrytan/gstack/blob/main/review/SKILL.md) | Reuse existing mechanisms and reason about structural and practical risk. Engineering Review used this lens for assessment. Closeout retains authorized repair and recheck. |
| [Anthropic / code-review](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/code-review) | Filter low-signal issues and check relevant context. No automatic inline comments or PR mutations. |
| [Sentry / find-bugs](https://github.com/getsentry/skills/tree/main/skills/find-bugs) | Map changed surfaces, inspect real enforcement and report unverified areas. Adapt the checklist to material task risks. |
| [ui-evidence](https://github.com/0xBrewing/ui-evidence) | Before/after browser evidence, optional existing tool. Appearance and actual business behavior are verified separately. |
| [Agent Skills specification](https://agentskills.io/specification) | Portable directory and frontmatter; progressive disclosure through reference files. |
