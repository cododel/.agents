# Inventory And Provenance

Determine first-party universe from tracked/nonignored untracked source plus relevant project configs.
Record roots/include/exclude, alternate/manual suites, support/setup hooks, maintained generated
tests, runtime/project multiplication and ignored vendor/build/cache copies. Config exclusion is not
obsolescence. Manual probes may read production settings; do not execute to count. Check collection
side effects and installed-tool profiles before imports. Disclose static-only or unresolved coverage.

Keep separate file counts, source definitions/registration sites, actual collected cases, statically
expanded declarations, assertion sites, subtest report events and runtime outcomes. Parameter cases
already belong to collection totals; internal body loops are not registrations. Static IDs are not
runtime titles/nodeids. Use originating locations/framework parsing: parameter values can contain
`::`, so naive nodeid splitting produces false definitions.

For frontend `each`/registration loops include declaration-level guards and config project selection.
Expand only resolvable source semantics; unknown expressions/guards get explicit unknown identities
and required safe collection evidence. Preserve registration ordinals when a guarded branch is absent.
Do not execute arbitrary code to make unknown counts look complete.

Validate unique IDs, item→definition/group mapping, unexplained uncollected definitions, alternate
populations and nonoverlapping batch membership. Reconcile earlier counts by source/config/profile
identity. External commits/removal/renames and corrected expansions are scope deltas, not audit
retirement verdicts. Preserve earlier snapshots and refresh affected mappings.

One primary semantic level per reviewed group: unit decision, component/service orchestration,
structural contract, DB integration, other real IO integration, browser/UI integration, system E2E
or unknown. Preserve unnormalized authored descriptions separately. Primary domain is exclusive;
secondary domains/scenario/assertion/mock/IO tags overlap and must not be summed. Filename/path and
file-context syntax signals are low-confidence routing metadata, not actual per-method boundaries
or quality verdicts. Browser with stub backend does not prove backend transactions.

Example: 10,070 collected Python + 1,757 static Vitest + 289 static Playwright is heterogeneous
bookkeeping, not executed-test total; 27 alternate source definitions are separate. A later guarded
registration can correct Vitest to 1,756 without removing a test. Reconcile such changes instead of
repeating a prior headline count. Never add historical subtest events to collected parents.
