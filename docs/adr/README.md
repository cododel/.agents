# Architecture Decision Records

This directory contains durable records of significant architecture decisions.

## Naming

Use `ADR-YYYYMMDD-<english-kebab-decision>.md`.

## Lifecycle

Use `Proposed`, `Accepted`, `Deprecated`, and `Superseded`. Accepted decision reasoning is immutable:
replace a changed choice with a successor ADR and link both records.
